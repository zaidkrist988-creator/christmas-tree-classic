# 璀璨圣诞树 · 手势控制粒子圣诞树（绿红金版）

照着 [nobody-r/christmas-tree](https://github.com/nobody-r/christmas-tree) 的功能从零实现的一版：星光粒子树、螺旋灯带、飘雪、礼盒、照片、音乐律动、三种手势切换。

这版是 **经典圣诞配色**：深绿树体配金色灯，红绿金三色礼盒铺在树下，树顶一颗暖金光晕，整体比冰蓝极光版更亮更喜庆。所有可调参数都集中在 `app.js` 顶部的一个配置对象里。

---

## 怎么跑

**双击 `启动.bat`**，浏览器会自动打开 `http://127.0.0.1:8765`。

它做的事就是起一个本地静态服务再开网页。摄像头只在 `localhost` 或 `https` 下能用，所以不能直接双击 `index.html`。

如果提示找不到 python：

```powershell
cd "这个文件夹的路径"
python -m http.server 8765 --bind 127.0.0.1
```

或者用 Node：

```powershell
npx -y serve -l 8765 .
```

然后手动打开 `http://127.0.0.1:8765`。

## 怎么玩

| 动作 | 效果 |
| --- | --- |
| 握拳 | 粒子汇聚成树 |
| 摊手 | 粒子炸成星云，灯带留在原地当骨架 |
| 捏指（拇指尖碰食指尖，其余三指伸开） | 照片从树里弹到树顶上方 |

- 第一次要点一下 **「开启手势」**，浏览器会弹摄像头授权。
- 右边小窗会实时画出 21 个手部关键点，方便你看识别有没有跟上。
- 没有摄像头、或者在手机上，用面板里的 **成树 / 散开 / 照片** 三个按钮切状态。
- 「添加照片」最多 6 张，会存进浏览器本地，**关掉再开会自动恢复**；缩略图上角 × 可删单张。
- 「添加音乐」选本地音频文件，树会跟着低频节拍呼吸。没有音乐时用正弦波模拟节拍。

## 改文字（唯一要动的地方）

打开 `app.js`，最上面 `CONFIG.text`：

```js
text: {
  kicker:    '2026 · CHRISTMAS',        // 标题上方的小字
  title:     '璀璨圣诞树',              // 主标题，也是浏览器标签页名字
  subtitle:  'Merry Christmas<br>愿你想见的人，都在光里',   // 支持 <br> 换行
  signature: '— 送给每一个还在等雪的人'                       // 落款
}
```

改完刷新页面即可。主标题是渐变文字，太长会换行，建议不超过 8 个字。

## 改树

同样在 `CONFIG.tree`：

| 参数 | 作用 | 建议范围 |
| --- | --- | --- |
| `height` | 树高 | 10 ~ 18 |
| `radius` | 底部半径，越大越胖 | 4 ~ 7 |
| `count` | 粒子数量 | 600 轻 / 1300 标准 / 2600 密 |
| `spin` | 自转速度 | 0 ~ 0.004 |
| `surface` | 粒子贴树面程度，越小越实心 | 0.75 ~ 0.95 |
| `thickness` | 树面随机厚度，越大越蓬松 | 0.1 ~ 0.4 |
| `colors` | 四个色值：主色 / 边缘色 / 紫色点缀 / 暖色点缀 | 任意十六进制 |
| `mix` | 暖色、紫色粒子的占比 | 0 ~ 0.3 |

当前这套（绿红金）的四个值是：

```js
colors: {
  core:   '#f4ffe6',   // 树体亮部，偏奶白绿
  edge:   '#1ab05a',   // 树体边缘，深一点的圣诞绿
  accent: '#ffc93c',   // 金色灯点
  warm:   '#ff4d3d'    // 红色装饰球
}
mix: { warm: 0.07, accent: 0.20 }   // 红只占 7%，金占 20%，剩下是绿
```

想要别的味道，只换这四个色值 + 两个占比即可。例如冰蓝极光版：`core '#ffffff' / edge '#7fd6ff' / accent '#b9a8ff' / warm '#ffe2a8'`，`warm 0.08 / accent 0.14`。

**想要更密的树**：`count: 2400`，同时把 `aSize` 生成式里的基准调小（在粒子生成循环里，`aSize[i] = 0.3 + Math.random() * 0.55 ...` 那一行，0.3 改 0.22）。

粒子的分层数量在 `const LAYERS = 26;`，改小（如 14）层会更粗更明显，改大更细腻。

## 调手势灵敏度

`CONFIG.gesture`：

```js
pinchDist: 0.46,     // 小于它算捏合，调大更容易触发捏指
stableFrames: 4,      // 连续几帧一致才切换，手抖就调大到 6
idleBack: 1.6         // 手离开几秒后自动回树
```

识别逻辑是纯几何，没有训练模型：

1. 用 MediaPipe HandLandmarker 拿到 21 个归一化关键点；
2. 四根手指各自比较「指尖到腕距离」和「PIP 关节到腕距离」，伸出就算 1 根（`ext`）；
3. `拇指尖↔食指尖 / 掌宽 < pinchDist` 且至少伸 1 根指 → 捏合；
4. `ext ≥ 3` → 摊手；`ext ≤ 1` → 握拳；其余保持上一状态。

所以**捏指的时候要把中指、无名指、小指伸开**，否则容易被判成握拳。

## 部署上线

纯静态，直接扔 GitHub Pages 就行：

1. 新建仓库，把整个文件夹传上去；
2. Settings → Pages → Source 选 `main` 分支根目录；
3. 等一分钟，拿到 `https://你的名字.github.io/仓库名/`。

`vendor/` 里的 Three.js、MediaPipe wasm 和手部模型都已在本地，不依赖外网 CDN，所以国内访问也稳。

注意：仓库如果超过 100MB 单文件限制——当前最大的是 `vision_wasm_internal.wasm`（9MB）和模型（7.6MB），没问题。

## 已验证 / 未验证

已验证：页面加载、3D 渲染（粒子树/灯带/礼盒/雪/树顶光晕）、散开状态、照片上传与弹出、IndexedDB 恢复、无 JS 报错。

未在真机上验证：真人手势触发（需要摄像头前实际挥手）、音乐节拍律动（需要真实音频）、移动端窄屏布局。

如果手势不灵，先看右边小窗的骨架是否在动——骨架在动但状态不切，就是阈值问题，按上面「调手势灵敏度」改；骨架不动，是摄像头权限或光线问题。
